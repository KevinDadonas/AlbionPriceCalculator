Como Funciona a Monitoria de Mercado

Entenda a origem dos preços, as especificações técnicas da API pública do Albion Data Project e as boas práticas de uso para evitar sobrecarga de memória.

📡

Origem dos Dados: Albion Data Project

Infraestrutura pública mantida pela comunidade

Esta aplicação consome a API REST pública do Albion Data Project. Trata-se de um ecossistema mantido pela comunidade onde os próprios jogadores alimentam o banco de dados via captura de pacotes de rede enquanto utilizam o mercado no jogo.

Coleta Passiva

Jogadores utilizam o cliente oficial do projeto (Albion Data Client) em segundo plano enquanto jogam.

Atualização On-Demand

Quando um jogador inspeciona as ordens do mercado em uma cidade, as informações vistas são enviadas para a API.

Principais Endpoints
GET /api/v2/stats/prices/{itemList}.json

Retorna o menor preço de venda e maior preço de compra para os itens informados.

locations=Caerleon,Bridgewatch qualities=1,2,3,4,5
GET /api/v2/stats/history/{itemList}.json

Retorna o histórico de volume e preços agrupados por intervalos de tempo (ex: 6 horas, 24 horas).

⏱️
Limites Oficiais de Requisição (Rate Limits):

Até 180 requisições por minuto (ou 300 requisições a cada 5 minutos). O tamanho máximo da URL é de 4096 caracteres, permitindo consultar dezenas de itens em um único lote.

Escopo de Monitoramento: O Mercado Negro (Black Market)

Entenda quais itens fazem parte da nossa base de dados e por que

Esta ferramenta é focada no monitoramento de preços para itens elegíveis ao Black Market de Caerleon. O Mercado Negro atua como o sistema gerador de loot do jogo: ele compra equipamentos diretamente dos jogadores para redistribuí-los como recompensas em baús e saques de monstros pelo mundo de Albion.

✓

Itens Permitidos (Monitorados)

  • • Armas: Todas as linhas (espadas, arcos, cajados, adagas, martelos, etc.), incluindo versões normais e de artefato.
  • • Armaduras: Peças de cabeça, peito e pés (Tecido, Couro e Placas).
  • • Mão Secundária (Off-hands): Escudos, tochas, grimórios, orbes, trompas, etc.
  • • Acessórios: Capas comuns, capas de facção e bolsas de todos os níveis.
  • • Ferramentas de Coleta: Machados, picaretas, foices, facas e martelos de pesca.
✕

Itens Não Aceitos (Fora do Escopo)

  • • Recursos: Minérios, pedras, madeira, fibras, couro, lingotes, blocos, etc. (brutos ou refinados).
  • • Consumíveis: Poções, comidas, montarias, tomos de conhecimento e poções de treino.
  • • Itens Especiais: Algumas armas de evento ou linhas exclusivas (como armas de cristal puras) não possuem ordens do sistema.
📌 Nota: Nossa lista de monitoramento é filtrada continuamente para excluir itens sem demanda no Mercado Negro, economizando chamadas de API desnecessárias.
⚡

Uso Consciente do Monitoramento

Evitando travamentos e consumo excessivo de memória

Controle de Execução Recomendado

Utilize o botão Iniciar / Pausar Monitoramento. Deixar o scanner varrendo infinitamente em segundo plano pode acumular milhares de objetos na memória da aba e consumir banda desnecessária.

Respeito às Taxas (Rate Limit) Proteção

Nossa aplicação faz requisições em lotes fracionados com pequenos intervalos de espera. Isso impede que seu endereço de IP seja bloqueado temporariamente pela Cloudflare da API (Erro HTTP 429).

🧮 Regras de Cálculo Aplicadas

Preço de Compra Menor valor de venda direta nas Cidades Reais
Taxa Descontada 8% de taxa (Sem Premium - Padrão)
4% de taxa (Com Premium) no valor final da venda
Preço de Venda Maior valor de compra no Mercado Negro / Caerleon
